## 交互细节

### 连线
- 从输出端口拖到输入端口
- 类型不兼容时拖出红色虚线 + 提示
- 双击连线可删除

### 节点操作
- 右键菜单：Copy / Paste / Delete / Create Prefab / Unpack
- Del 键删除选中
- Ctrl+C / Ctrl+V 复制粘贴
- Ctrl+D 复制节点

### 画布
- 鼠标滚轮缩放
- Space + 拖拽 平移
- Ctrl+A 全选
- Ctrl+G 框选打组（未来）

### 运行
- 顶部 ▶ 按钮 → 开始运行
- 运行中 ■ 按钮可停止
- 右键节点 → "从此节点开始运行"（单节点重跑）
- 右键节点 → "运行到此节点"
